# 活動報名網頁生成工具 — 為不熟悉程式的老師快速產生報名頁面

## 概述

提供一個簡易的 web 工具，讓學校老師（大專、高中、國中、小學）在不會寫程式的情況下快速產生活動報名網頁。使用者可上傳活動海報或填寫文字描述，系統自動生成活動頁面，並提供「報名」按鈕串接 Google 表單以收集報名資料。

## 目標使用者

- 老師、行政人員、學生會等在校辦活動的非工程背景使用者。

## 主要功能（MVP）

1. 上傳海報圖檔或輸入活動標題、時間、地點、說明。
2. 自動生成簡易活動頁面（可預覽與分享連結）。
3. 一鍵綁定/產生 Google 表單或填入既有 Google 表單連結以作為報名表單。
4. 報名按鈕導向 Google 表單（可選在新分頁或嵌入）。
5. 可自訂報名欄位（從 Google 表單同步欄位）。
6. 簡單的主題或版型選擇（圖片＋文字排版）。
7. 基本隱私與資料保護提示（不存放報名資料，或明確說明資料儲存位置）。

## 技術要點（可選）

- 前端：React / Vue + 表單 builder 元件（或直接產生 HTML 模板）。
- 圖片上傳：直接上傳至 S3 / 物件存儲，或使用第三方圖床（視部署決策）。
- Google 表單串接：透過把表單連結放在報名按鈕，或使用 Google Forms 的 prefill 參數自動填入部分欄位。
- 部署：Netlify、Vercel 或 GitHub Pages（若不需後端）。
- 若需報名資料匯入系統，考慮 OAuth 與 Google Sheets API（權限與隱私複雜度較高，MVP 可先透過表單）。

## 優先與注意事項

- MVP 建議先只支援把報名按鈕導向 Google Form（避免處理使用者資料與 OAuth 權限）。
- 圖片與內容上傳的儲存位置與流量成本需評估，建議提供第三方圖床或由使用者提供公開圖片連結作為選項。
- 若未來要直接蒐集並顯示報名資料，務必處理 GDPR/個資相關合規與存取權限。
- 考慮產生短網址或分享連結的可用性（例如自動部署到 pages/<id> 或產生可分享的 slug）。

## 延伸功能（非 MVP）

- 內建簡易表單建構器並儲存報名結果至後端（需處理資料保護）。
- 支援多語系（中文、英文）。
- 範本庫（多種活動版型可套用）。
- 報名統計與導出（CSV、Google Sheets 同步）。
